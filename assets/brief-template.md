## 完工前自查清單

> 只有「一般任務」「翻譯/內容產出」兩種類型的任務書需要附這段。
> Code Review 類型不改 code,不適用。Simplify 類型本身就是清理過度設計,不用再清理一次。

完成上面的變更後,在回報完工之前,依序自己做完下列檢查(一次做完,不要等下一句指令才做下一項):

1. 看一遍自己這輪改動的 diff,確認每個改動都在白名單範圍內、都是為了達成任務目標。
2. 檢查有沒有過度設計或不必要的複雜度,順手清掉。
3. 用挑剔的眼光重讀一次自己的 code(當作在 review 別人的 PR),抓得到就自己修。
4. 快速掃一遍有沒有明顯的安全問題(硬編碼密鑰、明顯的注入風險等)。
5. 實際跑一次 build / test,確認真的跑得動,不是憑感覺覺得應該沒問題。跑完檢查一下測試工具有沒有在白名單外留下副產物(例如 `.pytest_cache/`、`__pycache__/` 這類快取或編譯產物),有的話一併清掉。
6. 把改動 commit 起來(訊息自己取,不用等對方要求)。
7. 上面任何一步發現問題,自己修完再回報,不用等對方確認。

完工後在回報裡簡短說明:改了什麼、驗收條件是否都滿足、自查清單過了沒有。
