- [ ] 輸出 `FINDINGS.md`,每條發現都要有:檔案:行號、嚴重度、**具體會出錯的情境**(什麼輸入/什麼時序下會怎麼壞,不是空泛地說「這裡可能有問題」)、信心等級(`CONFIRMED` 讀過 code 確認過 / `PLAUSIBLE` 懷疑但沒把握)
